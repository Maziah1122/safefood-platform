# SAFEFOOD National Food Safety & MRL Surveillance Platform

An enterprise-grade, modular web application for monitoring MRL pesticide residues, supply chain logistics, and AI risk inference.

## 🚀 Setup Instructions in Visual Studio Code

1. Open VS Code and open the `safefood-platform` folder.
2. Install the **Live Server** extension.
3. Right-click `index.html` and select **"Open with Live Server"**.
